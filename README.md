# 데이터셋 구조 진단기 (dataset_scout)

분석을 시작하기 전에 **이 데이터로 무엇을 할 수 있고 어디가 위험한지**를 진단한다.
컬럼의 의미는 보지 않고 구조만 보므로, 컬럼명이 `customer_id`든 `VAR001`이든 동일하게 동작한다.

## 진단 항목

| 탭 | 내용 |
|---|---|
| 구조 진단 | 그레인(1행=무엇), 테이블 유형, 분산0 컬럼, 결측 |
| 관계 진단 | 조인키 후보, **조인 전 팬아웃 예측** |
| 유효구간 | 표별 커버 기간, 빈 구간, 공통 구간 교집합 |
| 검정 추천 | 변수 타입 조합 → 검정 방법, 효과 크기, 층화 비교, 다중비교 카운터 |
| 요약 | 발견된 문제 목록 |

## 검정 방법 추천 규칙

LLM을 쓰지 않는다. 사람이 결과 변수와 설명 변수를 고르면 나머지는 계산이다.

| 결과 | 설명 | 검정 |
|---|---|---|
| 범주형 | 범주형 | 카이제곱 (기대빈도 5 미만이면 2×2에 한해 Fisher로 자동 전환) |
| 연속형 | 범주형 2집단 | t검정 (Welch) + Mann-Whitney 병기 |
| 연속형 | 범주형 3집단 이상 | ANOVA + Kruskal-Wallis 병기 |
| 연속형 | 연속형 | 상관분석 (피어슨 · 스피어만) |

**p값과 함께 효과 크기를 항상 낸다.** 표본이 크면 사소한 차이도 유의해지므로
p값만으로는 크기를 알 수 없다. 2×2는 발생률 차이(%p)와 상대 비율까지 계산한다.

**층화 비교**로 제3의 변수를 통제하고, 층마다 방향이 뒤집히면 심슨의 역설을 경고한다.

**다중비교 카운터**가 세션 내 검정 횟수를 세어 본페로니 보정 기준과
최소 1회 오류 확률을 보여준다.

## 판정 원리

**테이블 유형 4종** — 이 분류가 이후 지표·검정 추천의 출발점이다.

| 유형 | 1행 = | 판별 |
|---|---|---|
| 마스터 | 개체 1개 | 유일키가 있고 다른 표가 그 키를 참조 |
| 이벤트 로그 | 사건 1건 | 대리키만 유일 + 다른 표의 기본키를 참조 |
| 패널/스냅샷 | 개체 × 기간 | (개체 + 날짜) 조합이 유일, 밀도 높음 |
| 집계 테이블 | 구분 × 기간 | 개체 식별자 없이 이미 group by됨 |

**함정 세 가지를 따로 처리한다.**

1. **대리키** — `usage_id` 같은 일련번호가 있으면 모든 표가 "마스터"로 보인다.
   대리키를 제외한 실질 그레인을 따로 찾는다.
2. **우연한 유일성** — 작은 데이터에서는 아무 조합이나 유일해진다.
   밀도(행 수 ÷ 고유값 곱)가 낮으면 우연으로 판정해 버린다.
3. **측정값을 키로 오인** — `duration_min`(1~60) 같은 숫자는 다른 숫자와 우연히 겹친다.
   고유값이 적은 숫자 컬럼은 키 후보에서 제외한다.

## 알 수 없는 것

- 컬럼이 **무엇을 뜻하는지** (구조만 봄)
- 빈 구간이 **'0'인지 '기록 누락'인지** (업무 지식 필요)
- 이 데이터로 **무엇을 물어야 하는지** (도메인 담당자만 앎)

정의를 확정하는 것은 사람의 몫이고, 이 도구는 그 앞단의 확인 작업을 줄인다.
